# 3_Designs — 设计

从「做什么」到「怎么做」。

## 产出物

| 文件               | 说明                                          |
| ------------------ | --------------------------------------------- |
| `ux_flows.md`      | 用户流程图（Mermaid）、关键交互               |
| `ui_specs.md`      | UI 规范、关键页面线框描述、设计语言           |
| `architecture.md`  | 系统架构、模块划分、部署拓扑                  |
| `data_model.md`    | 数据模型、ER 图、关键表结构                   |
| `api_design.md`    | API 契约（端点、入参、出参、错误码）          |
| `tech_stack.md`    | 技术栈选型与理由                              |

## 出口标准

- 任何工程师拿到这套文档，能开始独立编码而不需追问产品
- 架构图 + 数据模型 + API 契约 三件套已确认

## AI 行为

- 优先用 Mermaid 画图（流程、ER、时序），不要塞图片
- 技术选型必须给理由；非主流选型必须给「为什么不选主流」
- API 文档遵循 RESTful 或 GraphQL 之一，不混用
