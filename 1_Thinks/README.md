# 1_Thinks — 构思阶段

回答三个问题：**为谁做？解决什么？为什么是现在？**

## 产出物

| 文件                       | 说明                                       |
| -------------------------- | ------------------------------------------ |
| `problem_definition.md`    | 问题定义：现状、痛点、影响范围             |
| `user_personas.md`         | 用户画像：典型用户的角色、场景、目标       |
| `value_proposition.md`     | 价值主张：我们提供什么，凭什么用户会选我们 |
| `brainstorm.md`（可选）    | 头脑风暴笔记                               |

## 出口标准

用户能用一句话回答：**「这个 App 是给【谁】解决【什么问题】的，凭【什么】胜出。」**

## AI 行为

- **多问，少写**：先 3–5 个澄清问题，再动笔。
- 不讨论 UI、不讨论技术栈、不讨论商业模式细节。
- 写完每个文件给用户 5 行以内的摘要，让用户确认或修订。
