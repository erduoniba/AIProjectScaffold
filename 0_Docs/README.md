# 0_Docs — 参考资料

存放外部输入：行业报告、竞品资料、API 规范、设计规范、政策法规等。

## 建议子目录

- `industry/` — 行业研究
- `competitors/` — 竞品分析
- `specs/` — 外部 API 规范、设计规范
- `assets/` — 图片、PDF 等附件

## 命名约定

- 中文文件名可用，但建议用小写下划线英文：`competitor_xxx.md`。
- 资料来源必须注明：URL、抓取日期、是否需要更新。

## AI 行为

- 进入新阶段前，先扫一眼本目录是否有相关资料；有则在引用时显式链接。
- 不要瞎编数据。无资料时标注 `TODO: 待调研`，不要凭印象写。
