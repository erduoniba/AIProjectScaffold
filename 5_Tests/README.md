# 5_Tests — 测试

## 产出物

| 文件             | 说明                              |
| ---------------- | --------------------------------- |
| `test_plan.md`   | 测试范围、策略、环境              |
| `test_cases.md`  | 关键用例（手动 + 自动化清单）     |

## 测试金字塔

```
        E2E（少）
       ──────────
      Integration（中）
     ──────────────────
    Unit（多，但只测有逻辑的部分）
```

## 守则

- **关键路径必须有自动化**：登录、支付、核心动作
- **集成测试要打真实依赖**：用 testcontainers 起真实 DB，不要无脑 mock —— mock 通过 ≠ 生产能跑
- **只测有逻辑的代码**：CRUD 包装层不需要单测
- **测试要快**：单测 < 1s，整套 < 5min；慢的拆出去
