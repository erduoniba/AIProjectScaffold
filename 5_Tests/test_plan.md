# 测试计划

## 范围

- 在测：
- 不在测（暂时不覆盖）：

## 策略

| 类型     | 工具          | 覆盖目标          | 运行时机     |
| -------- | ------------- | ----------------- | ------------ |
| 单元测试 | Vitest / Jest | 核心算法、工具函数 | 每次提交     |
| 集成测试 | Vitest        | 关键 API + 真实 DB | PR、合并前   |
| E2E      | Playwright    | 主路径用户流程    | nightly + 发布前 |
| 手动测试 | —             | UI 视觉、交互细节 | 发布前       |

## 环境

- 本地：docker-compose 起依赖
- CI：GitHub Actions / GitLab CI
- 测试数据：fixtures + 工厂函数

## 准入 / 准出

- 进入测试：开发自测通过、CI 绿
- 退出测试：阻塞 bug 0、关键路径覆盖率 ≥ 80%
