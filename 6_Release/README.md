# 6_Release — 发布

## 产出物

| 文件          | 说明                       |
| ------------- | -------------------------- |
| `deploy.md`   | 部署文档：步骤、回滚预案   |
| `changelog.md`| 版本更新日志               |

## 发布检查清单（每次发布前过一遍）

- [ ] 所有 P0 用例通过
- [ ] Changelog 已更新
- [ ] 数据库迁移已演练（含回滚）
- [ ] 环境变量清单已更新
- [ ] 监控 / 报警已配置
- [ ] 回滚方案已确认（多久能回？谁来执行？）
- [ ] 关键人员在线（发布窗口期）

## 发布节奏

- 灰度：5% → 25% → 100%
- 节假日 / 周五下午原则上不发布
