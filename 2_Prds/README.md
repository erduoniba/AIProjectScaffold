# 2_Prds — 产品需求

把 1_Thinks 的构思转成可交付的功能清单。

## 产出物

| 文件               | 说明                                |
| ------------------ | ----------------------------------- |
| `prd.md`           | 产品需求文档主文件                  |
| `user_stories.md`  | 用户故事列表                        |
| `mvp_scope.md`     | MVP 范围：做什么、不做什么、为什么 |

## 关键产出：MVP 范围

MVP 必须做到「砍无可砍」：每个功能问一遍「不做行不行？」能不做就不做。

## 出口标准

- MVP 功能清单 ≤ 10 项
- 每项功能都对应至少一个用户故事
- 用户确认「这就是 V1 要发的东西」
